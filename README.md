# Equipment Maintenance Tracker

A small demo equipment maintenance tracking application

## Features

- View equipment inventory
- View equipment maintenance logs (many to one)
- Create new equipment
- Create new maintenance logs

## How it runs

The backend is C#; An ASP.NET Core Web API, using SQLite as a database and Enity Framework Core to communicate with the database

The frontend is Typescript, HTML and CSS; An Angular framework website

## Running the Application

### Backend

- Using terminal start up the backend using:

**cd backend/EquipmentMaintenance.Api**

then

**dotnet run**

### Frontend

- Using terminal start up the front using:

**cd frontend/equipment-maintenance**

then

**npm install**

then

**ng serve**

Then open:

http://localhost:4200
